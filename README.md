# Retrofy

![image](retrofy.png)

Music client for Legacy iOS (Requires a premium account)

- iOS 6+
- armv7s+ (rust in librespot forced this)
- Spotify playback
- Album art
- Search
- Lock screen and control center

App icons made by u/AmadeoOOFDeReddit


If testing yourself you need to get a clientID from the Spotify dev portal and place it in FoxMusic/FoxMusic-Info.plist as without a valid client ID it cannot work.
